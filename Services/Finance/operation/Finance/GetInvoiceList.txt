# REST API JSON Payload Documentation

## GET /api/invoices - Retrieve Invoice List

### Request (Query Parameters)
- pageNumber (int, default 1)
- pageSize (int, default 10)
- status (string, optional)
- companyFilter (string, optional)
- startDate (date, optional, yyyy-MM-dd)
- endDate (date, optional, yyyy-MM-dd)

### Example Request
GET /api/invoices?pageNumber=1&pageSize=10&status=Paid&companyFilter=Kerry&startDate=2018-01-01&endDate=2025-12-31
